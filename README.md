# MobileFuse iOS SDK Swift Package

This repository publishes the Swift Package Manager wrapper for the MobileFuse iOS SDK.

## Package URL

`https://github.com/mobilefuse/mobilefuse-ios-sdk-spm.git`

## Current Release

`1.10.0`

## Package Details

The Swift package delivers the MobileFuse iOS SDK as a binary XCFramework. Version `1.10.0` is downloaded from:

`https://cdn.mobilefuse.com/sdk/1.10.0.zip`
